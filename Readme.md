# Laboratory Result Report

This is the Czech Laboratory Report Implementation Guide published by HL7 Czech Republic. The continuous build is available at https://build.fhir.org/ig/HL7-cz/cz-lab/.

## Changes and feedback
Feedback and issues about this IG can be submitted via the [issues](https://github.com/HL7-cz/cz-lab/issues) page and will be incorporated into subsequent releases. The current issues board is available in the [Project board](https://github.com/orgs/HL7-cz/projects/2).
